---
title: 3. Model selection
description: Choosing a model that fits quality, latency and cost limits.
---

## 3.1 Model families

Linear models, gradient-boosted trees, deep networks, two-tower models, transformers. Trees dominate tabular data; deep models handle text, images and sequences.

## 3.2 Selection constraints

Latency, memory, cost, interpretability and data size narrow which families are realistic.

## 3.3 Architecture patterns

Multi-stage funnels, multi-task models with shared layers and several heads, and ensembles.

## 3.4 Build vs fine-tune vs API

Train from scratch, fine-tune a pretrained model, or call a hosted API. Trade control against speed and cost.
