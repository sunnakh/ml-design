## 5.1 Schema, freshness, completeness, distribution checks

Validate every batch automatically: expected columns and types, recent enough data, no missing partitions, and distributions within expected ranges.

## 5.2 Missing values, outliers, deduplication

Decide how to handle nulls and extreme values, and remove duplicates so they don't distort training.
