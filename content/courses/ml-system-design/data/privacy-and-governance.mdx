---
title: 8. Privacy, security & governance
description: Handling data safely and lawfully.
---

## 8.1 PII, anonymization, consent, deletion (GDPR)

Know which data is personal, minimize and anonymize it, respect consent, and support deletion requests.

## 8.2 Access control

Limit who can read which data, and audit access.

## 8.3 Data poisoning / adversarial data

Attackers can inject bad data to manipulate the model. Validate sources and watch for suspicious patterns.
