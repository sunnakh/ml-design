---
title: 7. Feature operations
description: Running features in production over time.
---

## 7.1 Monitoring

Track null rates, drift and freshness SLAs for every important feature.

## 7.2 Versioning, lineage, ownership

Version feature definitions, record where they come from, and give each one an owner.

## 7.3 Deprecation

Retire unused or broken features safely, checking which models still depend on them.

## 7.4 Privacy, PII, fairness constraints

Some features are restricted by law or policy. Check PII and fairness before adding them.
