---
title: 7. Packaging and MLOps
description: Shipping models repeatably.
---

## 7.1 Registry and versioning

Store versioned models with their data version, code and metrics, and promote them through stages.

## 7.2 Containers, reproducibility

Package the model with the same feature code and dependencies used in training.

## 7.3 CI/CD and retraining

Automate train → validate → register → deploy, including scheduled or triggered retraining.

## 7.4 Validation gates

Block a release automatically if the model fails data, quality or performance checks.
