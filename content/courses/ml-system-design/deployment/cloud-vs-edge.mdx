description: Where the model runs.

## 8.1 On-device constraints

Edge models get low latency, offline use and privacy, but must be small and power-efficient.

## 8.2 Hybrid split

Run a small model on the device and a larger one in the cloud when needed.

## 8.3 Shipping updates

Updating models on devices is slow and uneven, so plan for many versions in the field.
