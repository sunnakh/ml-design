---
title: E. Decisions
description: Turning results into ship or no-ship, then checking again.
---

## E1 Launch gates

Define in advance what must be true to ship: primary metric up, no guardrail regressions, slices OK.

## E2 Trade-offs

When metrics disagree, decide using the agreed priorities and the cost of each outcome.

## E3 Holdouts

Keep a small group on the old system long-term to measure lasting effects.

## E4 Re-evaluation

Re-check models after launch, because the world and the data keep changing.

## E5 Eval infra

Versioned test sets, reproducible evaluation pipelines and automated checks (including leakage tests), so evaluation stays trustworthy as data and code change.
